The VaTViT Platform

VaTViT is being built to bring market information, broker connections and risk tools into one workspace.

Core Features

Market Information

Market information will depend on available data sources and completed integrations.

Clear Transaction History

The platform is designed to make account activity easier to review and trace.

Risk Controls

VaTViT is being built with controls intended to help identify unusual activity.

Broker Connections

Broker connections are planned and depend on completed integrations.

Portfolio View

The product direction is to make information from supported accounts easier to review together.

Security and Privacy

Security and privacy requirements will be verified and communicated as the platform develops.

Planned Technology Stack

This is the intended technology direction, not a description of services already in production. The current public website uses HTML, CSS and JavaScript; the existing API runs on Node.js and Express. Migration will be incremental so existing pages and services remain available while replacements are built and tested.

Web and Mobile

React with TypeScript and JavaScript is planned for the web experience. React Native with TypeScript is the intended direction for mobile.

Core Services

Perl is planned for future core backend services and microservices. The current Node.js API will remain until service boundaries and migration tests are in place.

Community

Ruby is intended for infrastructure serving community subdomains, separately from trading and account services.

Trading Integrations and Data

MQL5 Expert Advisors and Python data-processing services are planned for future trading-system integrations. These are not currently available.

Markets in Development

The platform is being designed to support a broader market view. Coverage, data and broker access depend on completed integrations; no live trading availability is implied.

Kenyan Equities

Planned market information for Kenyan equities, subject to data availability and integration.

Foreign Exchange

Foreign-exchange information is a planned area; broker connections and trading access are not represented as available.

Digital Assets

Digital-asset portfolio information is a product direction, subject to supported data sources and integrations.

Commodities

Commodity information is planned for a unified view as data sources and integrations become available.
